Full AES encrypt / decrypt

Encrypt or decrypt any length input. Long inputs are split into 16-byte blocks automatically.

How to read the round states

AES-128 uses an initial key addition plus 10 rounds. For inputs longer than 16 bytes, each block is processed separately. The grids below show the first block's round states.

Encrypt

Plaintext moves forward through AES into ciphertext.

Decrypt

Ciphertext uses inverse steps to recover plaintext.

State

Each grid is the internal state after one round boundary.
